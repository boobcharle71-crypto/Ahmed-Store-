# Ahmed Store — ملفات الرفع إلى GitHub

الملفات المطلوبة:
- index.html — موقع العملاء
- admin.html — لوحة الإدارة
- supabase-config.js — اتصال Supabase
- schema.sql — قاعدة البيانات
- .github/workflows/pages.yml — نشر GitHub Pages
- README_AR.md — شرح

بعد رفع الملفات إلى المستودع:
1. افتح Settings > Pages.
2. اختر GitHub Actions كمصدر النشر إذا ظهر الخيار.
3. انتظر نجاح عملية النشر.
4. رابط المتجر عادةً: https://USERNAME.github.io/ahmed-store/
5. رابط الإدارة: https://USERNAME.github.io/ahmed-store/admin.html

لا تضع Secret key أو service_role key في GitHub.
